# Парсер этимологического словаря

## Назначение

Автоматическое извлечение и структурирование статей из PDF-файлов этимологического словаря в XML-формат TEI Lex-0.

---

## Запуск

### 1. Извлечение текста из PDF

```
python extract_text_gui.py
```

### 2. Парсинг в TEI Lex-0

```
python main.py
```

### 3. Выверка лемм с Excel

```
python -m replace_lemmas.gui
```
